# Image Captioning System

An **end-to-end Image Captioning Pipeline** that generates descriptive captions for images using **Computer Vision** and **Natural Language Processing (NLP)**.  
This project integrates **deep learning, API deployment, and cloud deployment** for real-time caption generation.

---

## **Key Features**

- **Computer Vision + NLP Pipeline:**  
  - **ResNet50 Encoder** for image feature extraction  
  - **Seq2Seq Transformer Decoder (TensorFlow)** for generating captions

- **Real-Time API Deployment:**  
  Exposed via **FastAPI** for dynamic image uploads and caption inference.

- **Production-Ready Deployment:**  
  - **Dockerized containers** for easy deployment
  - **CI/CD with GitHub Actions**  
  - **Deployed to AWS**
