# Poetry Generator

A **Transformer-based Poetry Generation Model** trained on **Shakespeare’s sonnets**.  
This project leverages **Natural Language Generation (NLG)** to create coherent and stylistically consistent poetry, deployed as a real-time API service.

---

## **Key Features**

- **Transformer Decoder Architecture:**  
  - **Positional Encoding** and **Attention Mechanisms** for sequence modeling  
  - Trained on **Shakespeare’s sonnets** for stylistic accuracy

- **Real-Time API Deployment:**  
  Accessible via **FastAPI**, allowing users to generate poetry on-demand.

- **Production-Ready Pipeline:**  
  - **Dockerized API**  
  - **CI/CD automation with GitHub Actions**  
  - **Deployed to AWS**
